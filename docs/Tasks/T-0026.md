# T-0026: Streamlit config keys — remove `streamlit_port`, wire `streamlit_ttl_seconds`

**Created:** 2026-11-25 | **Status:** [ ] Not Started | **Origin pitch:** none
**Branch:** `task-T-0026-streamlit-config-keys` | **Base:** `dev`
**Related:** pre-tst docs audit (code-suspect B1). The user decided the code's behaviour is right: Streamlit Apps take
their port from the Service App range, and an idle TTL ends them.

## Context

`process_manager.streamlit_port` and `process_manager.streamlit_ttl_seconds` in `src/latarnia/core/config.py` have no
effect: `StreamlitManager` allocates ports through `port_manager.allocate_port(app_id, 'streamlit')` from
`process_manager.port_range`, and uses a hard-coded `self.default_ttl = 300`. Both keys are only echoed by
`GET /api/config` (`src/latarnia/main.py` ~637-638). Config that does nothing misleads operators.

## Goal

The UI Manager's idle TTL comes from `process_manager.streamlit_ttl_seconds`, and the unused `streamlit_port` key is gone.

## Touches

- `src/latarnia/core/config.py` — remove `ProcessManagerConfig.streamlit_port` (Pydantic ignores the key if a host
  `config.json` still has it).
- `src/latarnia/managers/streamlit_manager.py` — `self.default_ttl = config_manager.config.process_manager.streamlit_ttl_seconds`.
- `src/latarnia/main.py` — drop `streamlit_port` from the `/api/config` response.
- `tests/unit/` — cases below.
- `docs/System/architecture.md`, `docs/System/app-specification.md`, `docs/SYSTEM.md` — remove the "currently unused"
  notes (doc-updater, step 6).
- **Pattern reference:** how `StreamlitManager.__init__` reads other values from `config_manager`; `tests/unit/test_config.py`.

## Tasks

- [ ] Remove `streamlit_port` from `ProcessManagerConfig` and from `/api/config`.
- [ ] Read the TTL from `process_manager.streamlit_ttl_seconds` in `StreamlitManager.__init__`.
- [ ] Unit tests.

  `ProcessManagerConfig` has no `streamlit_port` attribute.
- **t26-003:** `grep -rn streamlit_port src/` → no matches.
- **t26-004:** Full suite green on ENV=dev.
