# T-0020: API docs move to the platform's `/docs` namespace, behind login

**Status:** [DONE]
**Branch:** `task-T-0020-platform-api-docs`
**Created:** 2026-10-19
**Related:** [I-0002](../Pitches/I-0002.md) App REST API (this task ships first; I-0002 only adds the `/rest/{app}/` route)

## Context

API docs are public and live inside each App's URL space:

- `/docs` and `/openapi.json` (the platform's) are served with no auth on an internet-facing host.
- Caddy routes `/apps/{app}/docs*` and `/apps/{app}/openapi.json` to the App with no auth and identity headers
  stripped (`src/latarnia/caddy/manager.py`). Every App's full API schema is public, and any App route under
  `/docs` is silently made anonymous. For latarnik, `/apps/latarnik/docs` reads as its own Documents concept, not
  API documentation.
- The dashboard has no link to any API docs.

## Plan

All API docs become platform pages under `/docs`, a platform-owned prefix no App can occupy:

| Docs | URL | Visible to |
|------|-----|------------|
| Latarnia | `/docs` (`/openapi.json`) | any logged-in user |
| An App's UI API | `/docs/apps/{app}/ui` | users with a role other than `none` on that App |
| An App's App REST API | `/docs/apps/{app}/rest` | role other than `none` on that App, by session or Machine Token |

- [x] **Caddy:** drop the public `/docs*` and `/openapi.json` blocks and the per-App `/apps/{app}/docs*` and
      `/apps/{app}/openapi.json` blocks. `/docs*` and `/openapi.json` fall into the catch-all `forward_auth` block.
      `/apps/{app}/docs` and `/apps/{app}/openapi.json` become ordinary protected App routes.
- [x] **App docs pages:** the platform fetches the App's `/openapi.json` directly from its port, splits it by path
      prefix (`/api/` → UI API, `/rest/` → App REST API), rewrites the server URL so "Try it out" targets the public
      path (`/apps/{app}/api/…` and `/rest/{app}/…`), and renders each half with Swagger UI. The pages live under
      `/docs/apps/{app}/{ui|rest}` (browser, session via the catch-all `forward_auth`). The split schemas are served
      as platform API at `/api/docs/apps/{app}/{ui|rest}`, so `JWTAuthMiddleware` accepts a session or a Machine
      Token there and consumers can generate clients. Both check the caller's role on that App.
- [x] **No OpenAPI, or no routes under a prefix:** that docs page returns 404 and its tile button is hidden.
      An unreachable App gives a clear "App not running" page, not a 500.
- [x] **Dashboard:** an "API docs" button in the header (→ `/docs`). On each Service App tile, "UI API" and
      "REST API" buttons, shown only when that half has at least one route.
- [x] **App spec (`docs/System/app-specification.md`):** Reserved Paths become `/health` and `/openapi.json`. The
      latter is an internal contract, read by the platform and never published by Caddy. `/docs` is no longer
      reserved; Apps may use it. Document where an App's docs now live and that `/api/` and `/rest/` are the
      prefixes the platform documents. Update the trust and `public_routes` notes that mention the `/docs` bypass.
- [x] **Fixture:** `example_full_app` keeps its UI API routes under `/api/` and gets one route under `/rest/`, so
      both docs pages and both tile buttons are exercised.
- [x] `docs/System/architecture.md` and `workflows.md` updated (doc-updater) for the Caddy route table and the docs flow.

Out of scope: the `/rest/{app}/` route itself and its auth (I-0002); routes outside `/api/` and `/rest/` (not
documented by the platform); Streamlit Apps (no docs buttons).

Promotion triggers: one feature (API docs) across the Caddyfile generator, a platform route and the dashboard
template. No schema change, no new service, three scopes or fewer. Stays a Task.

**Breaking change:** anything reading `/docs`, `/openapi.json` or `/apps/{app}/docs` anonymously stops working.
`/apps/{app}/docs` now reaches the App's own route behind login, so an App that keeps FastAPI's default Swagger
there still serves it, but only to logged-in users. Recommend `docs_url=None` in the spec.

## Acceptance

- **t20-001:** Generated Caddyfile → no block serves `/docs*`, `/openapi.json`, `/apps/{app}/docs*` or
  `/apps/{app}/openapi.json` without `forward_auth`.
- **t20-002:** Anonymous `GET /docs` and `GET /openapi.json` → redirected to `/auth/login`, not 200.
- **t20-003:** Logged-in user with no role on any App → `GET /docs` 200 (platform Swagger).
- **t20-004:** User with `webUI-low` on `example_full_app` → `GET /docs/apps/example_full_app/ui` 200; the schema
  lists only `/api/…` paths with server URL `/apps/example_full_app`.
- **t20-005:** Same user → `GET /docs/apps/example_full_app/rest` 200; the schema lists only the `/rest/…` path,
  shown relative to server URL `/rest/example_full_app`.
- **t20-006:** User with role `none` on `example_full_app` → both docs pages and both `/api/docs/apps/example_full_app/*` schemas return 403.
- **t20-007:** Machine Token scoped `{example_full_app: webUI-low}` → `GET /api/docs/apps/example_full_app/rest` 200;
  token scoped to another App only → 403.
- **t20-008:** App with no `/rest/` routes (`example_companion`) → `/docs/apps/example_companion/rest` 404 and no
  "REST API" button on its tile.
- **t20-009:** App stopped → its docs page shows "App not running", status not 500.
- **t20-010:** Dashboard → "API docs" header button links to `/docs`. The `example_full_app` tile shows "UI API"
  and "REST API" buttons linking to the two docs pages.
- **t20-011:** An App route at `/docs/x` → reachable at `/apps/{app}/docs/x` only with a session, with identity headers.
- **t20-012:** Unit suite still green: `PYTHONPATH=src python3 -m pytest tests/ -q`.
