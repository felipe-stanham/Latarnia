## Context

- `MCPGateway.on_app_version_bump` (`src/latarnia/managers/mcp_gateway.py` ~460) has no call site; the backward-
  compatibility check already runs in `on_app_started` after the App restarts (`_update_existing_app` says so).
- Redis pub/sub is no longer used by the platform, but leftovers remain: `RedisMessageBusClient` and the pub/sub channel
  helpers in `src/latarnia/core/redis_client.py` (`get_active_channels`, `RedisHealthMonitor._get_active_channels` and the
  `channels` field of the Redis metrics), `EventSubscriberConfig.channels` in `src/latarnia/core/config.py` and in
  `config/config.example.json`, and `examples/example_full_app/app.py` publishing to `latarnia:events:app` ("for
  dashboard recent activity" — nothing subscribes).

## Goal

The code no longer carries the unused MCP version-bump hook or Redis pub/sub machinery.

## Touches

- `src/latarnia/managers/mcp_gateway.py` — delete `on_app_version_bump` (keep the check in `on_app_started`).
- `src/latarnia/core/redis_client.py` — delete `RedisMessageBusClient` (after confirming no caller) and the pub/sub
  channel helpers; drop `channels` from the Redis metrics.
- `src/latarnia/core/config.py`, `config/config.example.json` — remove `event_subscriber.channels` (Pydantic ignores the
  key in host `config.json` files).
- `examples/example_full_app/app.py` — remove the `latarnia:events:app` publish (keep the Redis Stream publish).
- Tests that cover only the removed code — delete; tests of kept code — keep green.
- `docs/System/*` — remove the T-0029 known-limitation notes (doc-updater).
- **Pattern reference:** T-0024/T-0025-style small removals; `tests/unit/` modules for redis_client and mcp_gateway.
